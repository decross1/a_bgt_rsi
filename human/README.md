# `human/` — researcher-facing documentation

This directory contains everything you (the researcher) need to do
your part. Agents do not consume these files; they're written in your
voice, with your cadence in mind.

## What's here

- [`daily_plan.md`](daily_plan.md) — Day-by-day prose for Week 1
  (Days 31–37). The blocks you run each day; the `[GATE]` points
  where the agent halts for you; the cross-cutting rules.
- [`learning_track.md`](learning_track.md) — The parallel reading +
  problem-set rail. Sequenced across Phase 1 with target weeks but no
  hard deadlines. Block 1 progress lives here; it does **not** gate
  Block 2 in `plan.yaml`.
- [`reading_list.md`](reading_list.md) — Quick-reference list of every
  Phase 1 reading by source (Osborne & Rubinstein, Cesa-Bianchi &
  Lugosi, etc.) grouped by topic. Useful when you finish a chapter
  ahead of schedule and want to know what's next.
- [`days_01_30_recap.md`](days_01_30_recap.md) — Stub recap of Phase 0
  (pre-Week-1 preflight). Not day-by-day; one-paragraph framing + a
  decisions-locked table + known unknowns going into Day 31.
- [`retrospectives/`](retrospectives/) — Weekly attestation files
  (`week1.md`, `week2.md`, …) that record alignment evidence and
  trigger phase-boundary advances. See
  [`../agent/autonomy.md`](../agent/autonomy.md) §4 for what makes a
  retrospective load-bearing.
