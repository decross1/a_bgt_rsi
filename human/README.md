# `human/` — researcher-facing documentation

This directory contains everything you (the researcher) need to do
your part. Agents read [`sessions/`](sessions/) for current focus;
the rest is yours.

## What's here

- [`sessions/`](sessions/) — Per-session working notes,
  `YYYY-MM-DD.md`, one per working day. The day's plan and the
  end-of-session retrospective. Live source of truth for what's
  being worked on. See [`sessions/README.md`](sessions/README.md).
- [`learning_track.md`](learning_track.md) — The reading +
  problem-set rail. Sequenced with target weeks but no hard
  deadlines. Block 1 progress lives here; it does not gate code work.
- [`reading_list.md`](reading_list.md) — Quick-reference list of every
  reading by source (Osborne & Rubinstein, Cesa-Bianchi & Lugosi,
  etc.) grouped by topic.
- [`days_01_30_recap.md`](days_01_30_recap.md) — Stub recap of Phase 0
  (pre-Week-1 preflight).
- [`retrospectives/`](retrospectives/) — Weekly attestation files
  (`week1.md`, `week2.md`, …). The attestation's old role of
  unlocking autonomy tiers is retired; what remains is a regular
  cadence for the researcher to reflect.
