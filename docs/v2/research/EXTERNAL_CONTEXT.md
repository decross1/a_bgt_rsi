# External context for the v2 research program

This is a bounded literature screen supporting the repository audit, accessed 2026-09-14. It does not establish novelty for a proposed experiment. Papers below were checked at their original arXiv records; detailed results and code still need examination before a scientific preregistration claims replication or novelty.

| Source | Verified scope | Implication for v2 |
| --- | --- | --- |
| Horton, Filippas and Manning, *Large Language Models as Simulated Economic Agents*, arXiv 2301.07543v2, revised 2026-02-26, [primary paper record](https://arxiv.org/abs/2301.07543v2) | Treats model agents as simulated subjects with assigned endowments, information and preferences. | Record these experimental inputs explicitly; model behavior is not automatically evidence about humans. |
| Huynh et al., *Understanding LLM Agent Behaviours via Game Theory*, arXiv 2512.07462v2, 2025-12-11, [primary paper record](https://arxiv.org/abs/2512.07462v2) | Extends FAIRGAME with payoff-scaled repeated dilemmas and public-goods environments; reports framing/model/language sensitivity. | A new study needs counterbalanced framing, fixed model/policy identity and trajectory-level analysis. |
| Yao, Chen and Zhang, *Competition and Cooperation of LLM Agents in Games*, arXiv 2604.00487v2, 2026-04-11, [primary paper record](https://arxiv.org/abs/2604.00487v2) | Studies resource allocation and Cournot interactions; reports cooperation under some multi-round prompts. | Cooperation and Nash-consistent behavior are distinct outcomes; neither should be assumed to be universally better. |
| Chupilkin, *Multi-Agent Strategic Games with LLMs*, arXiv 2605.03604v1, 2026-05-05, [primary paper record](https://arxiv.org/abs/2605.03604v1) | Studies a repeated security dilemma, including horizon and communication variations. | Incentives, communication and finite-horizon behavior are established research directions, not unoccupied novelty claims. |
| Anthropic, *Demystifying evals for AI agents*, 2026-01-09, [official evaluation guidance](https://www.anthropic.com/engineering/demystifying-evals-for-ai-agents) | Distinguishes tasks, repeated trials, graders, traces and final outcomes; discusses code/model/human grading. | Maintain executable task contracts and complete cost/failure traces; a successful tool call is not necessarily a completed task. |

The proposed first v2 study should start as a synthetic calibration with mathematically checkable payoffs and actions. Any claim that agent incentives, language, or history have a novel effect requires a subsequent literature check, matched conditions, and a preregistered held-out experiment. Self-reported reasoning is an output to audit, not direct proof of the cause of an action.
