Reviewers: Codex maintenance implementation agents, separate maintenance

## Blocking findings resolved

- Historical tests read growing operational ledgers. Reconstruction now uses
  already-public study artifacts and explicitly synthetic non-target records.
  Exact scientific rows, aggregates and subprocess hash-seed checks remain.
- The first fixture proposal copied ignored paper/ledger content. All raw
  gzip/tar/feedback copies were removed before commit. The delivered fixture
  directory contains only reviewed source, provenance and documentation.
- Two benchmark helpers ignored explicit source paths. Metadata hashing and
  cluster reconstruction now use the caller's input; synthetic regressions
  exercise missing global paths.
- Cache expiry validation admitted nonfinite timestamps, and identity binding
  omitted transport/provider changes. Validation and invalidation now cover
  those cases. Unknown provider epochs bypass reuse; epochs do not prove a
  provider's mutable alias stayed fixed.
- Cache review routing could accept invalid cross-provider confirmation.
  Role/vendor checks reject those records. Runtime cache storage is ignored
  by Git, bounded and disabled by default.
- A stale machine-topic mirror survived agenda consumption. The selector now
  checks existing durable exact-topic consumption or successful dispatch
  evidence, preserves human/failed work, and filters before applying its cap.
- A first queue-repair draft treated finalized loop memory as success. Nara
  can finalize degraded iterations, so that evidence was removed. Ambiguous
  or mixed coordinator outcomes do not suppress a retry.
- Cycle logging inherited the first suggestion's source after selecting a
  different topic. It now matches the actual topic and leaves unmatched or
  conflicting attribution unknown.

The reviewed Qwen pilot has frozen manifests and explicit budget/decision
rules. Its tasks are public development material; repetition is not additional
independent task evidence. Manifest-only validation is distinguished from
no-call configuration resolution and endpoint/resource checks.
