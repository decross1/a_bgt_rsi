The acquisition script stages each day in an `_attempts` sibling and moves it to the canonical day directory only after `--fetch-public` returns successful ZIP/CHECKSUM validation and a hash-bound 24-hour processing receipt. It keeps stdout/stderr and any failed staging child for audit. On resumption it leaves existing canonical children untouched, prints that they still need the final 60-day admission, and fetches only absent days. It makes **no** model call, paid API call, order, or account request. The archive adapter does **not** journal each failed checksum/ZIP HTTP GET; the script records each issued *day-level fetch invocation* and its failure, while exact per-GET denominator proof is unavailable for failed historical attempts. The separate incremental Spot collector does journal every issued GET. Acquisition completion and a trade-only reference result must be reported separately; the latter assumes 10 bps fee plus 5 bps slippage per leg (30 bps roundtrip; doubled 60 bps), uses last-trade reference prices, and cannot establish executable net return. The actual account fee tier, forward spread and forward fillability remain unobserved.

For forward collection, keep `hourly_capture --run-once` manual initially. The earlier historical-source 09:04/09:05 lineage lacks preserved collector source bytes, and the deliberately capped 09:11 branch is incomplete. Neither may donate a future cursor. The timer is offset **30 seconds after each five-minute boundary**. It holds shared leases through one at-most-90-second capture; a prior exclusive research lease yields `skipped_busy`. Before GPU work, place `_scheduler/pause_capture` so an already-started tick cannot race the controller's lease acquisition; remove it after restoration. State becomes `attempting` before HTTP and `active` only after exact-source `continued_complete`; failed/interrupted attempts cannot donate a cursor. A verified active predecessor older than 15 minutes archives its state and writes `gaps/gap-*.json` with old/new IDs and the unobserved interval **before** any new GET, then starts a new independent venue-tail lineage. It never joins the missing interval or fetches backlog through the stale cursor. Source, schema, pointer, failed-attempt and interrupted-state drift still block.
