The acquisition script stages each day in an `_attempts` sibling and moves it to the canonical day directory only after `--fetch-public` returns successful ZIP/CHECKSUM validation and a hash-bound 24-hour processing receipt. It keeps stdout/stderr and any failed staging child for audit. On resumption it leaves existing canonical children untouched, prints that they still need the final 60-day admission, and fetches only absent days. It makes **no** model call, paid API call, order, or account request. The archive adapter does **not** journal each failed checksum/ZIP HTTP GET; the script records each issued *day-level fetch invocation* and its failure, while exact per-GET denominator proof is unavailable for failed historical attempts. The separate incremental Spot collector does journal every issued GET.
