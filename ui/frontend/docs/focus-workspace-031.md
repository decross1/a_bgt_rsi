# Focused Research workspace

The existing `/ladder` route now opens one selected thesis and up to three recorded claim entries. The three exact Liquid Democracy summaries lead that collection when their source identities and hypothesis text match the existing dated notes. Selecting a claim shows concise evidence and next-test context beside the canvas. On narrow screens the context replaces the membership pane; Back returns focus to the selected claim.

The compact selector searches received titles, topics, record/iteration IDs and hypothesis text. Family identity survives reorder; a removed selection is cleared, and member order does not change claim identity. Rendering is bounded to forty selector options and three claim entries. Search reaches other options; the full record browser remains in **Records and sources**.

That disclosure retains the original filters, collection cards, Board/Table, counts, source timestamps, unknown categories, killed history and detailed inspector. Closing it returns to the canvas without throwing away selection. Source refresh errors remain visible outside the disclosure. Full hypotheses, dated blockers/test proposals, independent scientific/application/evidence/execution states, provenance and dossier links remain inspectable. Collection membership never means evidence, equivalence or scientific progress. Supplied outcomes stay unverified; absent compatible-test evidence is not a negative experiment result.

The source scope is limited to Ladder, ResearchCanvas, their route/canvas/retained-family tests and this note. No backend, API schema, model, service, scientific status or action writer changes. The source branch starts from public `d77bff93a2241ab469add854b3f8a7c6db595198`; private canonical history is excluded from publication.

The initial draft and failures were retained: its twelve-entry canvas and long context failed visual acceptance; five focused tests failed. One corrective integration reduced visible content, fixed search/identity behavior, corrected new fixture assumptions and restored the original six-response source-harness assertion. The existing 24-read ceiling was preserved, with fewer contexts materialized. The corrective focused set passed 102 tests.
