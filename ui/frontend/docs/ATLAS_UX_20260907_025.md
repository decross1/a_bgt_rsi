## How the interface behaves

- Now keeps dated human requests accessible in a disclosure. The lab queue is
  fetched only after **Load lab queue**; entering Now does not start its topic
  assessment. Existing cache and human-action semantics are unchanged.
- Research keeps Collections, Board, Table and dossier links. **Inspect context**
  opens the existing side panel. The Liquid Democracy collection features the
  three exact claims from the dated September 7 readiness assessment; other
  record/member histories remain accessible. Member entries and cluster counts
  have different denominators.
- The readiness notes match exact iteration ID, unique cluster identity and
  hypothesis text. They are dated engineering assessments and proposed tests,
  not accepted protocols or later-runtime attestations. Projection omissions
  cannot prove no later experiment exists. Claim standing, application fit,
  evidence validity and execution mode remain separate.
- Operations retains Delivery, Channel, Model I/O and diagnostic destinations.
  Model I/O puts the call feed before collapsed runtime and suggestion history;
  its retention, filter and polling logic is unchanged. A successful model call
  does not establish scientific support.
- Light is the default, with an in-memory fallback if theme storage is blocked.
  The dark option remains available. A narrow viewport uses a collapsible menu;
  existing route URLs and command-palette destinations remain valid.

## Review corrections

The first exact review blocked aggregate absence wording, eager family-history
rendering and narrow-menu keyboard behavior. The successor classifies outcome,
binding and comparison fields independently as missing, explicit null, unsupported
shape or supplied object; raw supplied values remain inspectable and no validity
is inferred. Family histories use ten-entry pages with first/previous/next/last
controls and one selected detail. Building the lightweight identity index remains
linear in received entries; this is not a whole-application constant-memory claim.
Legacy record member and agenda lists retain their existing behavior.

The narrow menu moves focus inside, contains Tab traversal and returns focus when
closed. The palette coordinates with navigation and leaves an existing modal in
control. Scoped theme compatibility covers informative Channel notes and existing
chart marks; these are presentation changes, with all result values and status
semantics retained. Synthetic chart fixtures are qualification inputs only.
