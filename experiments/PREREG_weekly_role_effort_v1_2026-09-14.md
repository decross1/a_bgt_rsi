# Role-aware reasoning pilot

Frozen before calls. Six fresh game-theory tasks, two each for criticism, evidence extraction, and tool selection. Seed 71; three arms rotated per task: fixed xhigh, fixed medium, adaptive. All use exact resident Qwen, temperature .2/top_p .95, 4096 generated tokens and 90 seconds total per task-arm. The adaptive critic starts xhigh; other roles start medium with at most half the token/time budget. Only a returned response failing its public output schema or explicitly setting needs_review=true can trigger one xhigh attempt using the remaining cumulative token/time allowance. Hidden answer correctness never enters routing. Transport timeout has no blind retry. No schema salvage. Final attempt is scored, all attempts and costs remain recorded.

Reservation 1660 seconds; payload 1630 seconds, 18 task-arms, at most22 calls. Exact manifest/runner/parser/grader hashes are bound by the existing weekly controller. No paid calls or production policy change. The execution fixtures measure tool selection/arguments, not full multi-turn tool chains. Expected answers are evaluator-only and are not included in messages.

Primary outcomes: exact task completion separately by role, protocol failure class, escalation count, all-attempt time/tokens, and transport failures. Citation arrays are an unordered set of exact IDs. A successful adaptive arm must preserve task success while reducing total cost on this panel; six tasks at one seed cannot support promotion regardless of result. Follow-up confirmation requires more held-out tasks and multiple seeds. There is no significance claim or post-hoc threshold tuning. Preserve all negative and incomplete outcomes.
